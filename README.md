# player

Минималистичный музыкальный плеер для терминала. Python 3 и FFmpeg (`ffplay`, `ffprobe`); сторонние Python-пакеты не нужны.

```bash
player "/путь/к/музыке"
player                       # повторно открыть последнюю папку
```

Плеер ищет аудиофайлы во вложенных папках и показывает их деревом. Каждая папка и её треки выделены своим приглушённым цветом, если терминал поддерживает цвета. Папки с музыкой можно сворачивать и раскрывать клавишей `Enter`. Сворачивание скрывает строки списка, но не прерывает воспроизведение: треки по-прежнему идут по порядку названий (числа сортируются естественно). После последнего трека воспроизведение начинается снова с первого.

| Клавиша | Действие |
| --- | --- |
| `↑` / `↓` | Выбрать песню или папку |
| `Enter` | Запустить песню или свернуть/раскрыть папку |
| `←` / `→` | Перемотать на 10 секунд |
| `Space` | Пауза / продолжить |
| `n` / `p` | Следующая / предыдущая песня |
| `q` / `Esc` | Выход |

Последняя папка хранится в `${XDG_STATE_HOME:-~/.local/state}/player/last_playlist.json`.

## Яндекс Музыка (ветка `feature/yandex-music`)

Для входа в аккаунт нужна дополнительная библиотека. Установите её в отдельное окружение:

```bash
cd /home/pc/projects/terminal-player
python3 -m venv .venv
.venv/bin/pip install -r requirements-yandex.txt
player --yandex
```

При первом запуске плеер покажет адрес и код для входа через браузер. Пароль и токен в плеер вводить не нужно. После входа появятся «Мне нравится» и ваши плейлисты; треки воспроизводятся по сети через `ffplay`. Наличие подписки и доступность отдельных треков определяет Яндекс Музыка. Токен хранится локально в `${XDG_STATE_HOME:-~/.local/state}/player/yandex_auth.json` с правами доступа только для вашего пользователя. Когда токен истечёт, плеер предложит войти снова.

Локальные папки по-прежнему открываются командой `player <папка>`.
